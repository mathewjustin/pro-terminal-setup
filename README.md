# Pro Terminal Setup

A portable Ghostty/zsh terminal setup with Starship, zoxide, fzf, eza, bat,
fd, ripgrep, kubectl aliases, k9s, and tmux.

## Install From A Homebrew Tap

After publishing the tap:

```sh
brew tap justin/pro-terminal
brew install pro-terminal-setup
pro-terminal-setup install
```

Then open a new terminal and run:

```sh
terminal-intro
```

## Check Tools

```sh
pro-terminal-setup doctor
```
